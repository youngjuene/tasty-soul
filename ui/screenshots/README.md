# 현재 모습

`npm run design` 을 라이트 모드 브라우저(1280×683)에서 찍었다.
**작업 전 기준선**이며, 화면을 고치면 다시 찍어 갱신하면 된다.

| 파일 | 화면 |
|---|---|
| `01-ingest.jpg` | 화면 1 투입 |
| `03-soul.jpg` | 화면 3 SOUL.md |
| `05-dashboard.jpg` | 화면 5 대시보드 |
| `06-archive.jpg` | 화면 6 아카이브 |
| `07-setup.jpg` | 설정 |

여기 없는 것: 화면 2·2.1 카드(투입 후에 뜬다 — `파일 고르기` 를 누르면 목이 카드를 만든다),
화면 4 승인 diff(SOUL 탭 아래쪽), §D7 고지(최초 실행에만).
전부 `npm run design` 에서 직접 볼 수 있다.

다크 모드는 OS 설정을 바꾸거나 브라우저 devtools 의
`Rendering → Emulate prefers-color-scheme` 로 확인한다.
