> 지금 모습을 보려면 **`npm run design` 을 직접 띄워라.** 아래 이미지는 "무엇이
> 어떻게 바뀌었는지" 를 보는 용도로만 쓴다.
>
> 찍은 뒤에 바뀐 것:
>
> - **전 화면** — 식별자(`other_reason` · `surprisal` · `grain` · `full`)가 우리말
>   뒤로 물러났다. 화면마다 접힌 «이게 무슨 뜻인가요»(`Explain`)가 생겼다.
> - **화면 1** — 두 카드가 각각 무엇을 묻는지 설명하는 문단이 붙었다.
> - **화면 3** — 문서 아래에 어긋남 패널(`Alignment`)이 생겼다.
> - **화면 5** — `(drift, crystal)` 산점도와 시간 스트립을 **뺐다.** 패널이 둘이다.
> - **화면 6** — 사이드바가 전부 우리말이 되었다 (`패싯` → `좁히기` 등).
> - **설정** — 모델 슬롯 이름이 "사진을 보는 모델" 처럼 하는 일로 바뀌었다.
>
