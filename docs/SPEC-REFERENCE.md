# § 참조 색인

이 저장소의 코드 주석과 문서는 **2065곳**에서 `§` 번호로 설계 명세를 참조한다.
원본 명세(`tasty-soul-mvp-plan.md`)는 공개하지 않으므로, 참조가 가리키는 곳이 무엇인지
이 표로 대신한다.

주석의 근거를 따라갈 때 쓴다. 규칙의 **전문**이 아니라 **무엇에 관한 절인지**만 적는다 —
규칙 자체는 해당 코드의 doc comment(`//!`)에 이미 옮겨져 있고, 그쪽이 진실이다.

## 최우선 규약

가장 자주 참조되는 것들이다. 이 규칙이 깨지면 크래시 없이 **데이터만 틀려진다.**

| § | 무엇 | 어디에 구현되어 있나 |
|---|---|---|
| **R1** | 시간 기준점 — 모든 파생값은 `T_ref`(최대 `ts`) 기준. `now()`는 관측 기록과 git 커밋에만 | `soul-core/src/time.rs` |
| **R2** | 재빌드는 재호출이 아니라 **재생**. LLM 출력을 관측에 기록해 두고 되살린다 | `soul-core/src/rebuild.rs` |
| **R3** | 임베딩만이 유일한 네트워크 예외. `--offline`이 캐시 미스에서 에러 | `soul-core/src/db/embed_cache.rs` |
| **R4** | `min_dist`·`surprisal`은 투입 시점 값으로 **동결**. 재계산하지 않는다 | `soul-core/src/derived/surprisal.rs` |

| **R7** | 단일 writer — `soul/.write.lock` flock. 실패 시 **즉시 에러**, 대기 없음 | `soul-core/src/lock.rs` |
| **R8** | git 커밋 정책 — **쓰기 1회 = 커밋 1개**. 재렌더 계기는 4개뿐 | `soul-core/src/git.rs` |

| **R11** | 프롬프트 버전 기록 — 렌더 끝난 최종 프롬프트의 sha256을 관측에 남긴다 | `soul-core/src/prompts.rs` |

## §18 — 조용히 망가지는 지점

크래시하지 않고 **데이터만 틀리게** 만드는 실패들이다. 구현 중 규칙을 완화하고 싶어지는
지점이므로 각각에 방어와 테스트가 붙어 있다. 전부 한 번씩 실제로 깨져 있었고 고쳤다 —
경위는 `OPEN-DECISIONS.md` 하단에 있다.

| # | 무엇이 조용히 망가지나 | 방어 |
|---|---|---|
| 1 | 프롬프트 수정이 **가짜 드리프트**로 나타난다 | `prompt_sha256` 기록 (§R11) |
| 2 | `supersedes` 필터를 한 곳만 빠뜨려도 축과 군집이 서서히 기운다 | `ObsSet::active_ingests()` 단일 관문 |
| 3 | 비평 임베딩이 섞이면 군집이 "무엇을 좋아하는가"에서 "무엇에 관해 글이 쓰였는가"로 흐른다 | `Space::Object` / `Space::Critique` 분리 |
| 4 | `SOUL.md`를 통째로 읽어 프롬프트에 넣으면 `soul:human`이 함께 나간다 | `soulblocks::assemble(_, Destination)` |
| 5 | 재렌더가 기존 파일을 읽지 않으면 사용자의 자유 기록이 사라진다 | `carry_over_human` + 원자적 쓰기 |
| 6 | 중간 선택지를 넣으면 응답이 거기로 몰리고 2×2가 무너진다 | `Verdict`는 `yes`/`no` 뿐 |
| 7 | 검색이 비면 모델이 그럴듯하게 채우고, 수집된 선호가 그 프레이밍에 대한 반응이 된다 | 근거 0건이면 관측 미생성 |
| 8 | 감각 글귀가 분류문으로 수렴하면 반박할 여지가 없어져 응답률이 0이 된다 | `needs_describe_retry` |

## 인수 테스트 T번호

`§17`의 T1–T71이다. 테스트 이름과 doc comment에 T번호가 그대로 적혀 있으므로
`rg 'T17'` 같은 방식으로 찾을 수 있다. 핵심만:

| T | 무엇 |
|---|---|
| **T1** | `rebuild --from-scratch --offline` 후 `SOUL.md` **바이트 동일** |
| **T12** | 같은 픽스처로 k-means 2회 → 군집 배정 동일 |
